# §6.5 死枝 [20] の不到達性の証明

本稿は、§6.5「簡約化」の $`\textrm{Red}`$ の定義中、$`M`$ が単項かつ $`M_{1,0}\gt 0`$ の場合に現れる
脚注 **[20]**（および **[19]**）の分岐
```math
M_{1,0} \gt  j_1 \ \text{または}\ (N_j)_{j=M_{1,0}}^{j_1} \in T_{\textrm{PS}} \setminus PT_{\textrm{PS}}
\ \Longrightarrow\ \textrm{Red}(M) := M
```
が決して起こらないこと、すなわち命題（単項性と $`\textrm{Red}`$ の関係）を、原著と同じ記号で証明する。

原著の証明は系（直系先祖の $`\textrm{Red}`$ 不変性）に依拠するが、それらは互いに依存している
（corrections.md **A10**）。ここでは系（直系先祖の $`\textrm{Red}`$ 不変性）を用いず、$`\textrm{Red}`$
出力の行 $`0`$ の値の単調性という独立な不変量から証明する。記号は §6.1–§6.5 の定義に従う。

---

## 1. 設定と主張

$`M \in PT_{\textrm{PS}}`$ とし、$`m := M_{1,0}`$ とおく。本稿では $`m \gt  0`$ を仮定する。
```math
B := ((j,j))_{j=0}^{m-1} \oplus_{\mathbb{N}^2} \textrm{IncrFirst}^{m}(M), \qquad
N := \textrm{Red}(B), \qquad j_1 := \textrm{Lng}(N)-1
```
とおく（$`B`$ は $`\textrm{Red}`$ の定義 [17] の被約引数である）。$`B`$ の先頭 $`m`$ 列は対角
$`((j,j))_{j=0}^{m-1}`$ であり、続く列が $`\textrm{IncrFirst}^{m}(M)`$ である。

> **命題（単項性と $`\textrm{Red}`$ の関係, $`m\gt 0`$）.**
> $`M_{1,0} \le j_1`$ かつ $`(N_j)_{j=M_{1,0}}^{j_1} \in PT_{\textrm{PS}}`$ である。

これにより [18] の前提が常に成り立ち、[19]/[20] の分岐は起こらない。

---

## 2. 補助補題

### 補題 1（$`\textrm{Lng}`$ の $`\textrm{Red}`$ 不変性, 既出）
任意の $`X \in T_{\textrm{PS}}`$ に対し $`\textrm{Lng}(\textrm{Red}(X)) = \textrm{Lng}(X)`$。

### 補題 2（$`\le_M`$ の $`\textrm{IncrFirst}`$ 不変性, 既出）
任意の $`X \in T_{\textrm{PS}}`$ に対し $`\le_X`$ と $`\le_{\textrm{IncrFirst}(X)}`$ は一致する。

### 補題 3（直系先祖による切片の単項性, 既出と同型）
$`X \in T_{\textrm{PS}}`$, $`a,b \in \mathbb{N}`$, $`a \lt  b \le \textrm{Lng}(X)-1`$ とする。
$`(0,a) \le_X (0,b)`$ ならば $`(X_j)_{j=a}^{b} \in PT_{\textrm{PS}}`$ である。

*証明.* 切片 $`X' := (X_j)_{j=a}^{b}`$ の祖先関係 $`\le_{X'}`$ は $`\le_X`$ の添字 $`a`$ 平行移動への
制限に一致する。よって $`(0,a)\le_X(0,b)`$ は $`(0,0)\le_{X'}(0,\textrm{Lng}(X')-1)`$ を与え、$`a\lt b`$ より
$`X'`$ は零項でないから、単項の定義より $`X' \in PT_{\textrm{PS}}`$。□

### 補題 4（親の存在の判定条件 (3), 既出）
$`X \in T_{\textrm{PS}}`$, $`j'_0,j'_1 \in \mathbb{N}`$ とする。
```math
\text{任意の } j \in \mathbb{N} \text{ に対し } j'_0 \lt  j \le j'_1 \Longrightarrow X_{0,j'_0} \lt  X_{0,j}
```
が成り立つならば $`(0,j'_0) \le_X (0,j'_1)`$ である。

### 補題 5（**新**：$`\textrm{Red}`$ 出力の左端の行 $`0`$ 最小性）
任意の $`X \in PT_{\textrm{PS}}`$ に対し、$`\textrm{Red}(X)`$ の左端は行 $`0`$ の最小値である。すなわち
```math
\text{任意の } j \in \mathbb{N},\ j \le \textrm{Lng}(\textrm{Red}(X))-1 \Longrightarrow
\textrm{Red}(X)_{0,0} \le \textrm{Red}(X)_{0,j}.
```

*証明.* $`\textrm{Red}`$ の再帰的定義に沿った帰納による（$`\textrm{Red}`$ の well-defined 性の整礎関係上）。
各分岐で局所的に閉じる（**どの分岐が選ばれるかには依存しない**）。

- $`X`$ 零項：$`\textrm{Red}(X) = ((0,0))`$。長さ $`1`$ ゆえ自明。
- $`X`$ 複項：$`X \in PT_{\textrm{PS}}`$ に反するので生じない。
- $`X`$ 単項かつ $`X_0=(0,0)`$（核）：$`\textrm{Red}(X)`$ は対角前置
  $`((j,j))_{j=0}^{\textrm{TrMax}(X)}`$ で始まるので $`\textrm{Red}(X)_{0,0}=0`$。行 $`0`$ の値は常に $`\ge 0`$
  だから $`0 \le \textrm{Red}(X)_{0,j}`$。
- $`X`$ 単項かつ $`X_0 \ne (0,0)`$ かつ $`X_{1,0}=0`$（行 $`0`$ 平行移動）：
  $`\textrm{Red}(X) = \textrm{Red}(X')`$（$`X'`$ は核へ移った列）であり、$`X'`$ は核ゆえ前項に帰着。
- $`X`$ 単項かつ $`X_{1,0}\gt 0`$：$`\textrm{Red}`$ の定義の if 分岐を場合分けする。
  - 生成分岐 [18]：前提より $`(Y_j)_{j=u}^{\,\cdot} \in PT_{\textrm{PS}}`$（$`u:=X_{1,0}`$,
    $`Y`$ は内側の $`\textrm{Red}`$ 出力）であり、出力は
    $`\textrm{Red}(X)_{0,j} = Y_{0,u+j} - Y_{0,u} + Y_{1,u}`$、特に
    $`\textrm{Red}(X)_{0,0} = Y_{1,u}`$。切片 $`(Y_j)_{j=u}^{\,\cdot}`$ は単項ゆえその左端 $`Y_{0,u}`$ は
    行 $`0`$ の最小（単項なら $`(0,0)\le(0,j)`$ より $`Y_{0,u} \le Y_{0,u+j}`$）。よって
    $`\textrm{Red}(X)_{0,j} \ge Y_{1,u} = \textrm{Red}(X)_{0,0}`$。
  - 不動分岐 [19]/[20]：$`\textrm{Red}(X) = X`$ であり、$`X`$ 単項より $`(0,0)\le_X(0,j)`$、ゆえに
    $`X_{0,0} \le X_{0,j}`$。

いずれの分岐も内側の $`\textrm{Red}`$ を被約な引数にしか適用せず、生成分岐の前提は局所的に与えられて
いるので、本補題は **[19]/[20] の不到達性に依存しない**。□

### 補題 6（**新**：核拡大の幹と接合点の下界）
$`M \in PT_{\textrm{PS}}`$, $`m=M_{1,0}\gt 0`$, $`B = ((j,j))_{j=0}^{m-1} \oplus_{\mathbb{N}^2} \textrm{IncrFirst}^{m}(M)`$ とする。
```math
\text{(i)}\quad m \le \textrm{TrMax}(B), \qquad\qquad
\text{(ii)}\quad J \le \textrm{Lng}(\textrm{Br}(B))-1 \Longrightarrow \textrm{Joints}(B)_J \ge m.
```

*証明.* $`B`$ の先頭 $`m`$ 列は対角だから、各 $`j\lt m`$ で $`(1,j) \lt_B^{\textrm{Next}} (1,j+1)`$ であり、
さらに $`m`$ 列目（$`=\textrm{IncrFirst}^m(M)`$ の先頭、行 $`1`$ 値は $`M_{1,0}=m`$）への接続から
$`(1,m-1) \lt_B^{\textrm{Next}} (1,m)`$ も成り立つ。よって $`\textrm{TrMax}`$ の定義より
$`\textrm{TrMax}(B) \ge m`$。これが (i)。

(ii) を示す。$`J \le \textrm{Lng}(\textrm{Br}(B))-1`$ とし $`f := \textrm{FirstNodes}(B)_J`$ とおく。
命題（$`\textrm{FirstNodes}`$ と $`\textrm{TrMax}`$ と $`\textrm{Joints}`$ の関係）より
$`f \gt  \textrm{TrMax}(B) \ge m`$ であるから $`f - m \ge 1`$ かつ $`f-m \lt  \textrm{Lng}(M)`$。
$`B`$ の行 $`0`$ は、$`m \le j`$ では $`B_{0,j} = M_{0,j-m} + m`$ であり（対角前置の後で
$`\textrm{IncrFirst}^m`$ により行 $`0`$ が $`m`$ 持ち上がる）、$`B_{0,m} = M_{0,0}+m`$。$`M`$ は単項なので
$`M_{0,0} \lt  M_{0,f-m}`$（$`0 \lt  f-m`$、行 $`0`$ 最小性）。ゆえに
```math
B_{0,m} = M_{0,0}+m \lt  M_{0,f-m}+m = B_{0,f}.
```
したがって $`m`$ は $`f`$ の真下にある行 $`0`$ の値がより小さい添字である。$`\textrm{Joints}(B)_J`$ は
$`(0,j) \lt_B^{\textrm{Next}} (0,f)`$ を満たす（一意な）$`j`$、すなわち $`f`$ の行 $`0`$ の直近の親であり、
それは「$`f`$ 未満で $`B_{0,\cdot}`$ が $`B_{0,f}`$ 未満となる最大の添字」である。$`m \lt  f`$ かつ
$`B_{0,m} \lt  B_{0,f}`$ よりこの最大の添字は $`\ge m`$、ゆえに $`\textrm{Joints}(B)_J \ge m`$。□

## 3. 主証明

### 3.1 長さと $`M_{1,0} \le j_1`$

対角 $`((j,j))_{j=0}^{m-1}`$ は長さ $`m`$、$`\textrm{IncrFirst}^m(M)`$ は長さ $`\textrm{Lng}(M)`$ ゆえ
$`\textrm{Lng}(B) = m + \textrm{Lng}(M)`$。補題 1 より
```math
\textrm{Lng}(N) = \textrm{Lng}(B) = m + \textrm{Lng}(M), \qquad
j_1 = \textrm{Lng}(N)-1 = m + \textrm{Lng}(M) - 1.
```
$`\textrm{Lng}(M) \ge 1`$ より $`j_1 \ge m`$、すなわち **$`M_{1,0} \le j_1`$**。

### 3.2 $`N`$ の行 $`0`$ の列値の評価

$`B`$ は核（$`B_0 = (0,0)`$）であるから、$`N = \textrm{Red}(B)`$ は核の場合の定義により対角前置
$`((j,j))_{j=0}^{\textrm{TrMax}(B)}`$ で始まり、その後に枝
$`\bigoplus_{J} \textrm{IncrFirst}^{e_J}(\textrm{Red}(N_J))`$ が続く（幹のみのときは枝は無い）。

**(a) 幹上（$`0 \le j \le \textrm{TrMax}(B)`$）：** 対角だから $`N_{0,j} = j`$。特に補題 6(i) より
$`m \le \textrm{TrMax}(B)`$ なので $`N_{0,m} = m`$、かつ $`m \lt  j \le \textrm{TrMax}(B)`$ なら $`N_{0,j} = j \gt  m`$。

**(b) 枝の中（$`\textrm{TrMax}(B) \lt  j \le j_1`$）：** 添字 $`j`$ が第 $`J`$ 枝塊に属するとする。その枝塊は
$`\textrm{Red}`$ の定義により $`\textrm{IncrFirst}^{e_J}(\textrm{Red}(N_J))`$ であり、左端の行 $`0`$ 値は
$`e_J + (\textrm{Red}(N_J))_{0,0}`$。$`B`$ は核ゆえ $`N_J`$ の左端は $`(\textrm{Joints}(B)_J+1,\,n_J)`$、
$`\textrm{Red}`$ の定義の指数は $`e_J = \textrm{Joints}(B)_J + 1 - n_J`$ であり、かつ
$`(\textrm{Red}(N_J))_{0,0} = n_J`$（$`N_J`$ の構成と補題 5・補題（$`\textrm{Red}`$ と左端の関係）より、
$`\textrm{Red}`$ は $`N_J`$ の左端の行 $`0`$ を $`n_J`$ に正規化する）。よって左端の行 $`0`$ 値はちょうど
$`e_J + n_J = \textrm{Joints}(B)_J + 1`$ である。補題 5 を $`N_J`$ に適用すると、枝塊内の各列の行 $`0`$ 値は
左端の値以上、すなわち
```math
N_{0,j} \ge \textrm{Joints}(B)_J + 1.
```
補題 6(ii) より $`\textrm{Joints}(B)_J \ge m`$ だから $`N_{0,j} \ge m + 1 \gt  m`$。

(a)(b) を合わせると、
```math
N_{0,m} = m, \qquad
\text{任意の } j,\ m \lt  j \le j_1 \Longrightarrow N_{0,j} \gt  m = N_{0,m}. \tag{*}
```

### 3.3 $`(0,m) \le_N (0,j_1)`$ と切片の単項性

$`(\ast)`$ は補題 4（親の存在の判定条件 (3)）の前提
「$`m \lt  j \le j_1 \Rightarrow N_{0,m} \lt  N_{0,j}`$」に他ならない。ゆえに
```math
(0,m) \le_N (0,j_1).
```
3.1 より $`m \lt  j_1`$（$`\textrm{Lng}(M)\ge 2`$ のとき；$`\textrm{Lng}(M)=1`$ のときは切片が長さ $`1`$ で
$`(N_j)_{j=m}^{j_1}=( (N_{1,m},N_{1,m}) )`$ 型の非零項単項として直接従う）であり、補題 3 を
$`X=N,\ a=m,\ b=j_1`$ に適用して
```math
(N_j)_{j=M_{1,0}}^{j_1} \in PT_{\textrm{PS}}.
```

以上より $`M_{1,0} \le j_1`$ かつ $`(N_j)_{j=M_{1,0}}^{j_1} \in PT_{\textrm{PS}}`$ が成り立ち、[18] の前提が
常に満たされる。したがって脚注 [19]/[20] の不動分岐は決して起こらない。$`\blacksquare`$

## 4. 補足

- 本証明が用いる新規補題は **補題 5**（$`\textrm{Red}`$ 出力の左端の行 $`0`$ 最小性）と
  **補題 6**（核拡大の幹・接合点の下界）の二つのみで、いずれも系（直系先祖の $`\textrm{Red}`$ 不変性）
  にも脚注 [19]/[20] の不到達性にも依存しない。これにより A10 に記した循環が解ける。
- 補題 5 の $`X_{1,0}\gt 0`$ の場合が局所的な分岐条件のみで閉じる点が、循環を避ける鍵である
  （生成分岐ではその場の前提として切片の単項性が与えられ、不動分岐では $`\textrm{Red}(X)=X`$ が
  単項性をそのまま使わせる）。
- 形式化（Isabelle/HOL）では補題 5 = `m_6_5_Red_leftend_row0_min`、補題 6(ii) =
  `joints_coreReduce_ge_m10`、本命題 = `m_6_5_monoT_Red_m10pos`。経験的検証は
  `python/red65_*.py`・`python/bc0*.py`・`python/piece3_routeA.py` ほか。設計の全経緯は
  `docs/red-le-domain.md §6–14`。
- $`M_{1,0}=0`$ の場合、原著の対角 $`((j,j))_{j=0}^{M_{1,0}-1}`$ は空列であり、命題自体は
  $`N=\textrm{Red}(\textrm{IncrFirst}^0(M))=\textrm{Red}(M)`$ について別途扱う（本稿の範囲外。
  なお Isabelle の `diagSeq 0 (M_{1,0}-1)` は自然数減算により $`M_{1,0}=0`$ で誤って単点列を
  与えるため、形式化では前提を $`M_{1,0}\gt 0`$ に明示する）。
