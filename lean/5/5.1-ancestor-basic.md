# §5.1 系（直系先祖の基本性質）

## 主張

$`M=(m_{ij})\in T_{\mathrm{PS}}`$ とし、$`j_0\lt j\le j_1`$ とする。

1. $`(0,j_0)\le_M(0,j_1)`$ ならば

   ```math
   m_{0j_0}\lt m_{0j}.
   ```

2. $`(1,j_0)\le_M(1,j_1)`$ かつ $`(0,j)\le_M(0,j_1)`$ ならば

   ```math
   m_{1j_0}\lt m_{1j}.
   ```

## 証明

親の定義から、上段の親

```math
(0,a)\lt^{\mathrm{Next}}_M(0,b)
```

について

```math
a\lt b,\qquad m_{0a}\lt m_{0b}
```

であり、さらに

```math
a\lt k\lt b\quad\Longrightarrow\quad m_{0b}\le m_{0k}
\tag{U}
```

である。また、下段の親

```math
(1,a)\lt^{\mathrm{Next}}_M(1,b)
```

について

```math
a\lt b,\qquad m_{1a}\lt m_{1b}
```

であり、さらに

```math
a\lt k\ \land\ (0,k)\le_M(0,b)
\quad\Longrightarrow\quad
m_{1b}\le m_{1k}
\tag{L}
```

である。

直系先祖関係 $`(i,a)\le_M(i,b)`$ は、反射的な場合 $`a=b`$、または有限な親子鎖

```math
a=q_0\lt q_1\lt\cdots\lt q_r=b,
\qquad
(i,q_\nu)\lt^{\mathrm{Next}}_M(i,q_{\nu+1})quad(0\le\nu\lt r)
\tag{C}
```

が存在する場合として読むことができる。以下では、この鎖の長さに関する帰納法を用いる。

### 上段の鎖

まず

```math
(0,a)\le_M(0,b),\qquad a\lt c\le b
\quad\Longrightarrow\quad
m_{0a}\lt m_{0c}
\tag{A}
```

を示す。

鎖の長さが $`0`$ なら $`a=b`$ となり、$`a\lt c\le b`$ に反する。

鎖の長さが正であるとき、その最初の一段を

```math
(0,a)\lt^{\mathrm{Next}}_M(0,p),
\qquad
(0,p)\le_M(0,b)
\tag{A1}
```

と書く。

#### $`c\le p`$ の場合

$`c=p`$ ならば、親の定義から

```math
m_{0a}\lt m_{0p}=m_{0c}
```

である。$`c\lt p`$ ならば $`a\lt c\lt p`$ なので、(U) より

```math
m_{0p}\le m_{0c}.
```

従って、この場合も

```math
m_{0a}\lt m_{0p}\le m_{0c}
```

である。

#### $`p\lt c`$ の場合

残りの鎖 $`(0,p)\le_M(0,b)`$ に帰納法の仮定を適用すると

```math
m_{0p}\lt m_{0c}
```

を得る。最初の親について $`m_{0a}\lt m_{0p}`$ であるから

```math
m_{0a}\lt m_{0p}\lt m_{0c}
```

となる。以上により (A) が示された。

(A) に

```math
a=j_0,\qquad c=j,\qquad b=j_1
```

を代入すれば、主張1を得る。

### 上段の直系先祖の区間性

次に

```math
(0,a)\le_M(0,b),\qquad a\le c\le b
\quad\Longrightarrow\quad
(0,a)\le_M(0,c)
\tag{I}
```

を示す。

$`a=c`$ ならば反射性より明らかである。$`a\lt c`$ とする。任意の $`a\lt k\le c`$ に対して
$`k\le b`$ でもあるから、(A) より

```math
m_{0a}\lt m_{0k}.
```

従って、親の存在に関する命題を $`a,c`$ に適用することにより

```math
(0,a)\le_M(0,c)
```

を得る。これで (I) が示された。

### 下段の鎖

最後に

```math
\begin{gathered}
(1,a)\le_M(1,b),\qquad a\lt c\le b,\cr 
(0,c)\le_M(0,b)
\end{gathered}
\quad\Longrightarrow\quad
m_{1a}\lt m_{1c}
\tag{B}
```

を示す。

下段の親子鎖の長さについて帰納法を行う。鎖の長さが $`0`$ なら $`a=b`$ となり、
$`a\lt c\le b`$ に反する。

鎖の長さが正であるとき、その最初の一段を

```math
(1,a)\lt^{\mathrm{Next}}_M(1,p),
\qquad
(1,p)\le_M(1,b)
\tag{B1}
```

と書く。親子鎖では列番号が狭義に増加するので $`p\le b`$ である。

#### $`c\le p`$ の場合

仮定 $`(0,c)\le_M(0,b)`$ と $`c\le p\le b`$ に上段の区間性 (I) を適用すると

```math
(0,c)\le_M(0,p)
\tag{B2}
```

を得る。

$`c=p`$ ならば、親の定義から

```math
m_{1a}\lt m_{1p}=m_{1c}
```

である。$`c\lt p`$ ならば、$`a\lt c`$ と (B2) に (L) を適用して

```math
m_{1p}\le m_{1c}
```

を得る。従って、この場合も

```math
m_{1a}\lt m_{1p}\le m_{1c}
```

である。

#### $`p\lt c`$ の場合

残りの鎖 $`(1,p)\le_M(1,b)`$ に帰納法の仮定を適用すると

```math
m_{1p}\lt m_{1c}
```

を得る。最初の親について $`m_{1a}\lt m_{1p}`$ であるから

```math
m_{1a}\lt m_{1p}\lt m_{1c}
```

となる。以上により (B) が示された。

(B) に

```math
a=j_0,\qquad c=j,\qquad b=j_1
```

を代入すれば、主張2を得る。$`\square`$
