# §5.1 命題（親の存在の判定条件）

## 主張

$`M=(M_{i,j})\in T_{\mathrm{PS}}`$ とし、

```math
j_0\lt j_1\lt\operatorname{Lng}(M)
```

とする。このとき、次が成り立つ。

1. $`M_{0,j_0}\lt M_{0,j_1}`$ ならば、ある $`j\in\mathbb N`$ が存在して

   ```math
   j_0\le j\lt j_1,
   \qquad
   (0,j)\lt^{\mathrm{Next}}_M(0,j_1)
   ```

   となる。

2. $`M_{1,j_0}\lt M_{1,j_1}`$ かつ $`(0,j_0)\le_M(0,j_1)`$ ならば、ある
   $`j\in\mathbb N`$ が存在して

   ```math
   j_0\le j\lt j_1,
   \qquad
   (1,j)\lt^{\mathrm{Next}}_M(1,j_1)
   ```

   となる。

3. 任意の $`j\in\mathbb N`$ に対して

   ```math
   j_0\lt j\le j_1
   \quad\Longrightarrow\quad
   M_{0,j_0}\lt M_{0,j}
   \tag{H0}
   ```

   ならば、$`(0,j_0)\le_M(0,j_1)`$ である。

4. $`(0,j_0)\le_M(0,j_1)`$ であり、任意の $`j\in\mathbb N`$ に対して

   ```math
   j_0\lt j,\quad (0,j)\le_M(0,j_1)
   \quad\Longrightarrow\quad
   M_{1,j_0}\lt M_{1,j}
   \tag{H1}
   ```

   ならば、$`(1,j_0)\le_M(1,j_1)`$ である。

## 準備

親の定義から、上段について

```math
(0,a)\lt^{\mathrm{Next}}_M(0,b)
```

ならば

```math
a\lt b,\qquad M_{0,a}\lt M_{0,b},
\tag{U1}
```

かつ

```math
a\lt k\lt b
\quad\Longrightarrow\quad
M_{0,b}\le M_{0,k}
\tag{U2}
```

である。下段について

```math
(1,a)\lt^{\mathrm{Next}}_M(1,b)
```

ならば

```math
a\lt b,\qquad M_{1,a}\lt M_{1,b},\qquad (0,a)\le_M(0,b),
\tag{L1}
```

かつ

```math
a\lt k,\quad (0,k)\le_M(0,b)
\quad\Longrightarrow\quad
M_{1,b}\le M_{1,k}
\tag{L2}
```

である。

また、直系先祖関係を構成する親子鎖では、列番号が各段で狭義に増加する。従って

```math
(i,a)\le_M(i,b)
\quad\Longrightarrow\quad
a\le b.
\tag{I0}
```

さらに、上段の親子鎖について次の二つの性質が成り立つ。

```math
(0,a)\le_M(0,b)
\quad\Longrightarrow\quad
M_{0,a}\le M_{0,b},
\tag{U3}
```

```math
(0,a)\le_M(0,b),\quad a\lt c\le b
\quad\Longrightarrow\quad
M_{0,a}\lt M_{0,c}.
\tag{U4}
```

実際、親子鎖の長さについて帰納法を行う。鎖が反射的なら (U3) は明らかであり、
(U4) の仮定は成立しない。鎖の最後の一段を

```math
(0,a)\le_M(0,p)
\lt^{\mathrm{Next}}_M(0,b)
\tag{C}
```

とする。(U3) は帰納法の仮定と (U1) から

```math
M_{0,a}\le M_{0,p}\lt M_{0,b}
```

と従う。

(U4) について、$`c\le p`$ ならば前半の鎖に帰納法の仮定を適用すればよい。
$`p\lt c\le b`$ ならば、$`c=b`$ のとき

```math
M_{0,a}\le M_{0,p}\lt M_{0,b}=M_{0,c},
```

$`p\lt c\lt b`$ のとき (U2) より

```math
M_{0,a}\le M_{0,p}\lt M_{0,b}\le M_{0,c}
```

である。従って (U3), (U4) が示された。

## 証明

### (1) 上段の親の存在

有限集合

```math
S_0
:=
\{\,k\lt j_1\mid M_{0,k}\lt M_{0,j_1}\,\}
```

を考える。仮定より $`j_0\in S_0`$ なので、$`S_0`$ は空でない。その最大元を $`j`$ とする。
すると

```math
j_0\le j\lt j_1,
\qquad
M_{0,j}\lt M_{0,j_1}.
\tag{1.1}
```

任意の $`k`$ に対して $`j\lt k\lt j_1`$ とする。もし

```math
M_{0,k}\lt M_{0,j_1}
```

ならば $`k\in S_0`$ となり、$`j`$ の最大性に反する。従って

```math
j\lt k\lt j_1
\quad\Longrightarrow\quad
M_{0,j_1}\le M_{0,k}.
\tag{1.2}
```

(1.1), (1.2) と上段の親の定義から

```math
(0,j)\lt^{\mathrm{Next}}_M(0,j_1)
```

である。これで (1) が示された。

### (2) 下段の親の存在

有限集合

```math
S_1
:=
\{\,k\lt j_1\mid
M_{1,k}\lt M_{1,j_1}
\ \land\
(0,k)\le_M(0,j_1)\,\}
```

を考える。仮定より $`j_0\in S_1`$ なので、$`S_1`$ は空でない。その最大元を $`j`$ とする。
すると

```math
\begin{gathered}
j_0\le j\lt j_1,\qquad M_{1,j}\lt M_{1,j_1},\cr 
(0,j)\le_M(0,j_1).
\end{gathered}
\tag{2.1}
```

$`j\lt k`$ かつ $`(0,k)\le_M(0,j_1)`$ とする。(I0) より $`k\le j_1`$ である。
$`k=j_1`$ ならば明らかに

```math
M_{1,j_1}\le M_{1,k}.
```

$`k\lt j_1`$ のとき、もし $`M_{1,k}\lt M_{1,j_1}`$ ならば $`k\in S_1`$ となり、
$`j`$ の最大性に反する。従って、いずれの場合にも

```math
j\lt k,\quad (0,k)\le_M(0,j_1)
\quad\Longrightarrow\quad
M_{1,j_1}\le M_{1,k}.
\tag{2.2}
```

(2.1), (2.2) と下段の親の定義から

```math
(1,j)\lt^{\mathrm{Next}}_M(1,j_1)
```

である。これで (2) が示された。

### (3) 上段の直系先祖の存在

$`j_1-j_0`$ に関する強い帰納法で示す。仮定 (H0) を $`j=j_1`$ に適用すると

```math
M_{0,j_0}\lt M_{0,j_1}
```

である。従って (1) より、ある $`p`$ が存在して

```math
j_0\le p\lt j_1,
\qquad
(0,p)\lt^{\mathrm{Next}}_M(0,j_1)
\tag{3.1}
```

となる。

$`p=j_0`$ ならば (3.1) そのものから

```math
(0,j_0)\le_M(0,j_1)
```

である。

$`j_0\lt p`$ とする。任意の $`j_0\lt k\le p`$ に対して $`k\le j_1`$ でもあるから、
(H0) より

```math
M_{0,j_0}\lt M_{0,k}.
```

しかも $`p\lt j_1`$ なので、帰納法の仮定を終点 $`p`$ に適用でき、

```math
(0,j_0)\le_M(0,p)
```

を得る。これと (3.1) を連結すれば

```math
(0,j_0)\le_M(0,p)
\lt^{\mathrm{Next}}_M(0,j_1),
```

従って

```math
(0,j_0)\le_M(0,j_1)
```

である。これで (3) が示された。

### 上段の直系先祖関係の区間性と推移性

(4) の証明に先立ち、(3) から二つの性質を導く。

まず、上段の直系先祖関係は区間に制限できる。すなわち

```math
(0,a)\le_M(0,b),qquad a\le c\le b
\quad\Longrightarrow\quad
(0,a)\le_M(0,c).
\tag{P}
```

$`a=c`$ ならば反射性より明らかである。$`a\lt c`$ ならば、任意の $`a\lt k\le c`$ に対して
$`k\le b`$ であるから、(U4) より

```math
M_{0,a}\lt M_{0,k}.
```

従って (3) を $`a,c`$ に適用して (P) を得る。

次に、上段の直系先祖関係は推移的である。すなわち

```math
(0,a)\le_M(0,b),qquad (0,b)\le_M(0,c)
\quad\Longrightarrow\quad
(0,a)\le_M(0,c).
\tag{T}
```

$`a=b`$ または $`b=c`$ の場合は明らかであるから、$`a\lt b\lt c`$ とする。
任意の $`a\lt k\le c`$ を取る。$`k\le b`$ ならば、最初の鎖に (U4) を適用して

```math
M_{0,a}\lt M_{0,k}
```

を得る。$`b\lt k`$ ならば、(U3) と二番目の鎖に対する (U4) から

```math
M_{0,a}\le M_{0,b}\lt M_{0,k}
```

を得る。従って再び (3) を $`a,c`$ に適用すれば (T) が従う。

### (4) 下段の直系先祖の存在

$`j_1-j_0`$ に関する強い帰納法で示す。

$`(0,j_1)\le_M(0,j_1)`$ は反射性により成り立つので、(H1) を $`j=j_1`$ に適用すると

```math
M_{1,j_0}\lt M_{1,j_1}
```

である。従って (2) より、ある $`p`$ が存在して

```math
j_0\le p\lt j_1,
\qquad
(1,p)\lt^{\mathrm{Next}}_M(1,j_1)
\tag{4.1}
```

となる。

$`p=j_0`$ ならば (4.1) そのものから

```math
(1,j_0)\le_M(1,j_1)
```

である。

$`j_0\lt p`$ とする。下段の親の定義 (L1) から

```math
(0,p)\le_M(0,j_1)
\tag{4.2}
```

である。また、仮定 $`(0,j_0)\le_M(0,j_1)`$ と
$`j_0\le p\le j_1`$ に区間性 (P) を適用すると

```math
(0,j_0)\le_M(0,p)
\tag{4.3}
```

を得る。

ここで $`j_0\lt k`$ かつ $`(0,k)\le_M(0,p)`$ とする。(4.2) と推移性 (T) より

```math
(0,k)\le_M(0,p)\le_M(0,j_1),
```

従って (H1) から

```math
M_{1,j_0}\lt M_{1,k}
```

である。よって、終点 $`p`$ に対しても (4) の仮定がすべて成り立つ。
$`p\lt j_1`$ なので帰納法の仮定を適用でき、

```math
(1,j_0)\le_M(1,p)
```

を得る。これと (4.1) を連結すれば

```math
(1,j_0)\le_M(1,p)
\lt^{\mathrm{Next}}_M(1,j_1),
```

従って

```math
(1,j_0)\le_M(1,j_1)
```

である。これで (4) が示された。$`\square`$
