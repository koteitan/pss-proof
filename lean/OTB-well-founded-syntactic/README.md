# $`OT_B`$ の整礎性 — 構文的証明

PSS 原文は $`(OT_B,\lt )`$ の整礎性を独立した命題として用い、根拠として
[Buc1] Lemma 2.2 を引用する。[Buc1] Lemma 2.2 自体は評価写像 $`o`$ の
意味論的性質であり、ここに置く定理とは異なる。

このディレクトリでは順序数への評価写像を使わず、Buchholz 項、基本列、
$`W_u`$ と可到達性によって、PSS 原文が必要とする整礎性を直接証明する。
